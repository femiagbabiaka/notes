# Moonshot ideas
A random place to put some ideas.

* LLM
** Cron Tool Calling
A long running llm inference server should have access to a tool that allows it to create and manage cronjobs.
Example usage: Given a list of stocks, the llm generates a cron that will request news articles related to those stocks daily, using a more capable model.
* Emacs Plugins
** Flowistry for Emacs
Will Crichton published this rustlang plugin for vscode that allows one to see "related" code on hover. For example, hover over a value that has been moved into a function, and you see only the code that interacts with that value, if any, until the value goes out of scope or is moved back out. The plugin is written in typescript of course, but the underlying parsing of rustc emitted IR, etc, done via compiler plugins, is not necessarily tied to the VSCode ecosystem. It would be interesting to write a Emacs version of this plugin.
